🎯 O QUE É CITIZENTECH?
═══════════════════════════════════════════════════════════════════════

CitizenTech é um sistema inteligente que:
  ✓ Coleta dados de tráfego em tempo real via API TomTom
  ✓ Armazena informações em um Data Warehouse (Snowflake)
  ✓ Usa um algoritmo inteligente para otimizar semáforos
  ✓ Reduz congestionamento urbano automaticamente
  ✓ Facilita o transporte coletivo (ônibus)

❓ DÚVIDAS FREQUENTES

P: Como funciona o algoritmo?
R: Ele:
   1. Coleta dados de tráfego (velocidade, tempo de percurso)
   2. Calcula o "fator de atraso" (quanto mais lento está)
   3. Se muito lento, aumenta o tempo do semáforo
   4. Se normal, mantém como está
   5. Registra a ação no banco de dados

P: Os dados são reais?
R: Parcialmente:
   ✓ Dados de tráfego: SIM (via API TomTom em tempo real)
   ✗ Dashboard: NÃO (ainda com dados de exemplo)
   
   Próxima fase: Integrar dados reais do Snowflake

P: Onde estão os dados?
R: Em Belo Horizonte! O sistema monitora as principais vias:
   • Avenida Afonso Pena
   • Avenida Getúlio Vargas
   • Rua Espírito Santo
   • Avenida Brasil
   E mais...

P: Posso modificar os mapas?
R: SIM! Abra qualquer .html em um editor de texto e modifique.

P: O que é o Data Warehouse?
R: Um banco de dados (Snowflake) que armazena:
   • Métricas de tráfego
   • Histórico de ajustes de semáforos
   • Informações de vias e bairros
   • Dimensões temporais

✅ VERIFICAÇÃO RÁPIDA

Para confirmar que tudo está funcionando:

1. Abra INICIAR_SISTEMA.bat
2. Escolha opção 5 (Testar Conexão com TomTom API)
3. Aguarde alguns segundos
4. Você deve ver:
   ✓ Conexão com TomTom bem-sucedida
   ✓ Dados coletados
   ✓ Fator de atraso calculado

Se não vir isso, verifique:
  • Conexão com a internet
  • Arquivo .env preenchido corretamente
  • Ambiente virtual ativado
