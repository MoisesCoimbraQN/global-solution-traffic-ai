═════════════════════════════════════════════════════════════════════════════
🔍 O QUE O SISTEMA FAZ
═════════════════════════════════════════════════════════════════════════════

A CADA 5 MINUTOS:

1. COLETA (coletor_transito_db.py)
   └─ Conecta à API TomTom
   └─ Pega dados de tráfego em tempo real
   └─ Armazena em PostgreSQL (fato_transito_tempo_real)

2. ANÁLISE (algoritmo_otimizacao.py)
   └─ Calcula fator de atraso (tempo_atual / tempo_livre)
   └─ Calcula score de congestionamento (0-100)
   └─ Classifica nível: LIVRE / MODERADO / INTENSO / CRÍTICO

3. PREVISÃO
   └─ Prevê congestionamento com 95% confiança
   └─ Identifica quando há problemas

4. DECISÃO
   └─ Se LIVRE: MANTER sinal (sem mudança)
   └─ Se MODERADO: AUMENTAR +10s
   └─ Se INTENSO: AUMENTAR +20s
   └─ Se CRÍTICO: PRIORIDADE +60s (máximo 120s)

5. AÇÃO
   └─ Semáforos são ajustados automaticamente
   └─ Novo tempo de verde é aplicado

6. AUDITORIA
   └─ Registra tudo em PostgreSQL (fato_ciclo_semaforo)
   └─ Histórico completo para análise
