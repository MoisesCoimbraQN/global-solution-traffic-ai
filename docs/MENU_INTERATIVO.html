Algoritmo Inteligente de Semáforos

Como funciona:

  • Monitora fluxo de tráfego via API TomTom
  • Calcula fator de atraso (tempo atual / tempo livre)
  • Ajusta ciclos de semáforos dinamicamente
  • Registra ações na tabela fato do Data Warehouse

Critérios de Decisão:

  • Fator ≤ 1.2: Manter ciclo padrão
  • Fator > 1.3: Ativar otimização
